# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

**Latest: 0.15.4** · 2026-10-14 · macOS 14 or later

Signed and notarized by Apple. Installed copies update themselves.

## What's new in 0.15.4

- Fixed: the picker could seem frozen when macOS kept another app in front. Your first click now picks right away, and Esc always closes the picker.
- macOS's own Screen Recording prompt and ColorPickr's alert no longer appear at the same time.
