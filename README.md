# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

## What's new in 0.15.2

- The color vision simulation is easier to leave: the pill under the menu bar now has a **Turn off** button, so you don't need to remember ⌃⌥V.
- Fixed: when Screen Recording access was missing, the alert asking for it could come straight back after you clicked Later.
