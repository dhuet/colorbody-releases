# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

## What's new in 0.19.0

- **ColorPickr for Figma:** a new Figma plugin turns your palettes, themes and design systems into Figma variables and color styles. Themes keep Light and Dark modes, and every role stays linked to the palette color it uses.
- New **For Figma** option under **Export › Copy to Clipboard** for palettes, themes and design systems. Free for palettes.
- **Buy ColorPickr Pro** now goes to the live store: one payment of $19.99, up to 3 devices across Mac and Chrome.
