# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

## What's new in 0.22.1

- Fixed: with a long History and every section open, the menu bar panel could grow taller than the screen and lose its top edge, often when coming back from the color picker. It now stops at the screen's height and scrolls, and always stays on screen.
