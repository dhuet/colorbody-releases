# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

## What's new in 0.15.0

- **Smart Formats:** a pick is copied in the format of the app you were working in. Pick while you're in Xcode and you get SwiftUI; pick while you're in VS Code, Cursor or Figma and you get HEX. Choose any app's format in Settings › General.
- The magnifier now says the color's name in plain words, like "dark blue" or "light grayish green", for anyone who can't trust their eyes on a hue.
- A cleaner menu bar panel: the color fills a big card with its hex, its name and where you picked it. Your four main formats sit up front with the rest one click away, and the contrast cards show real text so you can judge by eye. Fold History, the contrast check or Color vision to keep the panel short.
- One ColorPickr Pro key now covers up to 3 devices.
