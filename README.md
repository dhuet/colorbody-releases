# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

**Latest: 0.18.0** · 2026-10-26 · macOS 14 or later

[Download ColorPickr 0.18.0](https://github.com/dhuet/colorbody-releases/releases/latest/download/ColorPickr.dmg) · [Website](https://colorpickr.app) · [What's new](https://colorpickr.app/whats-new) · [Help](https://colorpickr.app/help)

Signed and notarized by Apple. Installed copies update themselves.

## What's new in 0.18.0

- **Theme Builder:** a guided first theme for when starting from nothing is the hard part. Start from a photo, a color or a mood, take a recommended main color and accent, and see the result on real screens in light and dark, with the reasons it works. Free to try; saving needs Pro.
- The Theme Builder is first under **Create**, on Home, in the panel's Library card, in the **File** menu and in the command palette. The Color Wheel moved to **More Tools**.
- Theme previews use a theme's accent color for small highlights.
