# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

Signed and notarized by Apple. Installed copies update themselves.

## What's new in 0.16.0

- **Quick Pick** (⌃⌥C) now uses the macOS magnifier: your screen stays live, click picks, Esc cancels. It needs no Screen Recording permission, so picking works the moment you install ColorPickr. A small card by the cursor shows what you picked, its name in plain words and the format it was copied in.
- **Precision Pick** (⌃⌥⇧C) is the frozen-screen picker, for 3×3 and 5×5 averages, pixel nudging and dragging an area into a palette.
- Screen Recording permission is now optional. It powers Precision Pick, Screen Check and the color vision simulation.
