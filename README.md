# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

## What's new in 0.22.0

- **iCloud Sync.** Your palettes, themes and mood boards, images included, on every Mac you use. Turn it on in Settings › Sync. It runs through a ColorPickr folder in your own iCloud Drive: no account, and nothing goes to ColorPickr. If the same item changes on two Macs at once, both versions are kept. Part of ColorPickr Pro.
