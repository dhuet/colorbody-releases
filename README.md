# ColorPickr

The color tool for Mac designers. Pick any color on screen, build palettes, mood boards and design systems, check contrast and export to code.

**Latest: 0.15.1** · 2026-10-14 · macOS 14 or later

[Download ColorPickr 0.15.1](https://github.com/dhuet/colorbody-releases/releases/latest/download/ColorPickr.dmg) · [Website](https://colorpickr.app) · [What's new](https://colorpickr.app/whats-new) · [Help](https://colorpickr.app/help)

Signed and notarized by Apple. Installed copies update themselves.

## What's new in 0.15.1

- Contrast fixes are smaller: ColorPickr now stops at the closest color that passes instead of a few shades past it, so your brand color changes as little as possible.
- New **Jetpack Compose** format, `Color(0xFFE9EEF7)`. Smart Formats uses it when you pick while working in Android Studio.
- Keyboard shortcuts in the menu bar panel: **⌘C** copies your default format, **⌘1** to **⌘4** copy the format tiles.
